# 🌌 Galaxy Memory Matching Game

An interactive **Memory Matching Game** built using **HTML, CSS, JavaScript, and jQuery** where players flip cards and try to match pairs within a limited time.

This project combines **logic building, DOM manipulation, animations, and sound effects** to create an engaging web-based mini game.

---

# 🎮 Project Overview

The **Galaxy Memory Matching Game** challenges players to find matching pairs of cards hidden on the board.

Each card contains a unique **space-themed emoji symbol**, and players must flip two cards at a time to find matches.

The player must match **all pairs within 60 seconds** to win the game.

If the timer reaches zero before all pairs are matched, the player loses.

# ✨ Features

### 🎴 Dynamic Card Generation
- Cards are generated dynamically using JavaScript
- Each game reshuffles the cards randomly

### 🔄 Card Flip Logic
- Players can flip **two cards at a time**
- Cards reveal a hidden symbol when clicked

### ✅ Matching System
- If cards match:
  - They remain flipped
  - A **correct match sound** is played
- If cards do not match:
  - They flip back after **1 second**
  - A **wrong sound effect** is played

### ⏱ Countdown Timer
- Players have **60 seconds** to complete the game
- Timer starts when the **Start Game** button is pressed

### 🎯 Move Counter
- Tracks the total number of moves taken by the player

### 🔄 Restart Game
- Restart button reshuffles cards
- Timer resets
- Game state restarts

### 🏆 Win Condition
- When all pairs are matched:
  - Timer stops
  - A **You Win message** appears

### ❌ Lose Condition
- If the timer reaches **0 seconds**
  - The game ends
  - A **Time Over message** appears

# ▶ How to Play

1. Click **Start Game**
2. Flip two cards by clicking on them
3. Try to find matching pairs
4. Match all pairs **before the 60-second timer ends**
5. Use **Restart Game** to start a new shuffled game
