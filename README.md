# 🎯 Guess The Number Game

An interactive and animated number guessing game built using **HTML, CSS, and JavaScript**.

---

## 🚀 Introduction

This is a simple yet engaging web-based game where the computer randomly selects a number and the player tries to guess it within limited attempts.

The game starts easy — but if you win, the difficulty increases automatically!

---

## 🎯 Objective

- Generate a random number.
- Allow user input.
- Provide feedback:
  - 📈 Too High
  - 📉 Too Low
  - 🎉 Correct!
- Limit attempts for challenge.
- Increase range after winning.

---

## 🕹️ How It Works

### 🔹 Level 1
- Range: 1 – 10
- Attempts: 3

### 🔹 Level 2 (After Winning)
- Range: 1 – 50
- Attempts: 5
